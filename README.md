# Java Banking System

A simple banking system built in Java as part of a Java Backend Developer roadmap.

## Features

* Account creation
* Deposits
* Withdrawals
* Money transfers between accounts
* Transaction history tracking
* Custom exception handling
* Account validation

## Technologies

* Java
* OOP
* Collections Framework
* Streams API

## Current Status

Implemented:

* Account management
* Bank entity
* Transaction tracking
* Business rule validation

Planned:

* Reporting features

* Unit testing

* REST APIs
