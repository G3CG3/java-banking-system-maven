# Java Banking System

A simple banking system built in Java as part of my Java Backend Developer roadmap.

---

## Features

- Account creation
- Deposits
- Withdrawals
- Money transfers
- Transaction history
- Transaction filtering
- Account search
- Account sorting
- Transaction sorting
- Bank reporting
- Bank statistics

---

## Architecture

- Layered Architecture (in progress)
- Service Layer

---

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- Java Streams API
